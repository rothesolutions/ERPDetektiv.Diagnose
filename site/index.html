ERPDetektiv Diagnose

Lokales Diagnosewerkzeug für Sage 100, Microsoft SQL Server und Windows. Es erstellt einen technischen Snapshot mit nachvollziehbaren Findings und einem teilbaren Diagnosepaket.

StartUmfangDiagnosepaketMitmachen

Wofür?

Für Situationen wie „Sage ist langsam“, „die Auftragserfassung hängt“ oder „was hat sich nach dem Update geändert?“. Das Werkzeug ersetzt keine Analyse. Es sammelt die technischen Grundlagen, die dafür sonst einzeln zusammengetragen werden müssten.

Schnellstart

$env:ERPDETEKTIV_SQL_CONNECTION = "Server=sqlsrv01;Database=master;Integrated Security=True;Encrypt=True"
dotnet run --project .\src\ERPDetektiv.Cli -- --output .\diagnose.zip --pseudonymize

Alternativ: Solution in Visual Studio öffnen und ERPDetektiv.Gui starten.

Was wird geprüft?

BereichBeispiele
WindowsBetriebssystem, Speicher, Laufwerke, Energieplan, relevante SQL- und Sage-Dienste
SQL ServerVersion, Konfiguration, Datenbanken, Backup-Stand, Query Store, Speicher, I/O-Latenz, PLE und Memory Grants
Sage 100Installation, Komponenten, Application Server, SData- und SOAP-Endpunkte

Fehlende Rechte oder nicht lesbare Bereiche werden im Erfassungsstatus angezeigt. Sie werden nicht als unauffälliges Ergebnis behandelt.

Was nicht?

  • Kein Monitoring und keine dauerhafte Überwachung.
  • Keine Telemetrie und keine automatische Datenübertragung.
  • Keine Änderung an Sage, SQL Server oder Windows.

Diagnosepaket

Der Export ist eine ZIP-Datei mit JSON-Snapshots, Findings, Erfassungsstatus, Prüfsummen und HTML-Zusammenfassung. Host- und Servernamen können konsistent pseudonymisiert werden. Zugangsdaten und Connection Strings werden nicht exportiert.

Vor dem Export prüft --preflight Verbindung, Berechtigungen, Sage-Erkennung und Zielpfad.

Projektstatus

v0.2.0 ist der erste öffentliche Pre-release. Das Werkzeug ist für reale technische Diagnoseeinsätze gedacht; Rückmeldungen zu fehlenden Daten, Fehlalarmen und unterstützten Umgebungen sind willkommen.

Für Fehler und Verbesserungen: GitHub Issue mit Tool-Version, Windows-/SQL-/Sage-Version, genauer Fehlermeldung und – falls möglich – pseudonymisiertem Diagnosepaket.
